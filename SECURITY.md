# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately to the maintainers by opening a [private vulnerability report]
(https://github.com/PyRo1121/omg-web/security/advisories/new) or emailing the
repository owner directly.

Please include:

- The affected component and version
- A minimal reproduction or description of the issue
- Impact and any suggested fix, if known

We aim to acknowledge reports within 48 hours and to keep you updated on the
fix and release timeline.

## Supported versions

Only the latest release on `main` receives security fixes.

## Disclosure

We will disclose fixed vulnerabilities after a release is published.
